# points

学習中に「気になったこと」「気づいたこと」を書き留めるディレクトリ。

## ルール

- 1トピック = 1ファイル
- ファイル名: `YYYY-MM-DD_トピック名.md`(例: `2026-10-10_server-components.md`)
- 同じトピックのファイルがすでにある場合は、新規作成せず追記する
- 追記するときは `## YYYY-MM-DD` の見出しを付けて日付ごとに分ける

## ファイルのフォーマット

```markdown
# トピック名

## YYYY-MM-DD

### 気になったこと / 気づいたこと
- (メモそのもの)

### 補足・解説
- (調べた内容や、関連するコードの場所 `app/xxx.tsx:12` など)

### 参考リンク
- [ページタイトル](URL) — そのページで確認できること

### 未解決・あとで調べる
- (残っている疑問)
```

- 補足・解説で公式などの出典に触れた場合は、確認できるリンクを「参考リンク」に必ず載せる。

## 書き方

Claude Code で次のように実行する:

```
/point Server Components で useState が使えないのはなぜ?
```

複数のメモをまとめて渡してもよい(トピックごとにファイルが分けられる)。
